EPhone v21 Core Edition

以 EPhone v19 穩定版為母版，新增獨立 /ephone/ Core。

EPhone Core 不依賴兔K機聊天詳情頁，資料儲存在 localStorage：EPhoneCore.v1。

功能：
- 動態角色／User 年齡
- 城市／地區地理位置設定
- Open-Meteo 地理搜尋與即時天氣
- 雙方距離、時差／時區、異地／異國判定
- 紀念日與週年倒數
- JSON 備份與還原

網址：部署後使用 /ephone/
天氣與地理搜尋需要網路連線；不需要 API key。


### v36 共同觀影記憶與外觀自訂
- 「共同觀影」可在外觀設定中自訂 App 名稱與 Icon。
- 每次真正讀取影片並產生角色回應時，會自動把影片片段、使用者談論與角色回應保存到該角色自己的長期對話記憶。
- 共同觀影記憶會隨角色私聊一起載入，僅在相關話題出現時自然參照。
- 觀影記憶可在角色的「對話記憶」介面查看、編輯、刪除。
- 沿用既有 GeminiChatDB，不建立新的資料庫。
